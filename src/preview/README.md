# 最终阶段试玩入口

以仓库 Debug 分支为基础移植导出试玩版的功能。原项目的主场景保持不变。

## 打开试玩

在 Godot 中打开 `preview/final_stage_preview.tscn`，按 F6（运行当前场景）。
启动后直接进入成人阶段，右侧可以进入成人农田、展开三个结局或按当前库存选择结局。
F5 仍然运行原来的完整游戏入口。此试玩场景也可在导出前设为主场景。

首次运行三种资源各 10B，之后读取 `user://inventory_final_preview.tres`。
普通游戏仍使用 `user://inventory.tres`。只有背包沿用原项目的保存功能，技能树不保存。
试玩结局按当前库存最多的一种选择；相同时优先苹果，其次花朵、蘑菇，不包含前两阶段累计值。
三个结局按钮用于试玩，不是原游戏的正常流程。
第三阶段合计资源达到 1T 自动进入结局，允许返回农田并继续选择其他结局。

## 修改范围

- 单独的试玩场景和控制脚本，不改正常游戏的初始阶段与主场景。
- 背包实例可指定存档路径，默认路径保持不变。
- 腐烂仍扣除原数值，视觉数量改为每种每次最多 40 个，避免为每单位损失创建计时器。
- 掉落图片不拦截鼠标点击。
- 仅在试玩控制器存在时使用试玩提交逻辑；普通流程的提交算法保持原样。
- 删除提交按钮连接到不存在方法的一条连接，保留实际处理方法。

扩地导致作物重置、普通流程的阶段提交错误等其他原版问题不属于此次修复范围。

## 自动检查

先用编辑器导入项目，然后运行：

```text
godot --headless --path <src目录> res://preview/final_stage_preview.tscn -- --preview-check
```

检查模式使用内存中的固定库存，不加载试玩存档，也不执行保存。
检查入口、各 10B、存档路径、按钮、三个结局、回农田、腐烂、1T 边界和并列判定。
已在 Windows / Godot 4.7.2 上验证；尚未验证原工程标注的 4.5 或其他平台。
原入口和试玩检查退出时仍有资源未释放提示，未在此次范围内全面排查。
